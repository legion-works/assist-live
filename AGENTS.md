# Repository rules

- Keep each repository file safe for public use.
- Keep personal data, network addresses, private paths, secrets, and household recordings out of this repository.
- Use documentation-range addresses when an address is necessary in an example.
- Keep the HA app and server in the different `assist-live-server` repository.
- Keep the ESPHome component in the different `assist-live-esphome` repository.
- Follow `docs/design.md` for design decisions and phase gates.
- Use public HA interfaces and the TTS lookup named in `docs/research/contracts.md` only.
- Keep the initializer free of import side effects.
- State that the project is experimental until a release has approval.
- Use ASD-STE100 for documentation and comments.
- Run the commands in `CONTRIBUTING.md` before review.
- Get operator approval before publication.
