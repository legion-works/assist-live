# Community rules

## Standards

Respect each participant.
Discuss the work, not personal qualities.
Do not use threats, harassment, sexual content, or personal attacks.
Do not publish other participants' private information.

## Scope and response

These rules apply to project discussions and to public statements made for the project.
Maintainers can remove dangerous content and prevent participation.
They give the cause of the decision without private report information.
Use a private maintainer contact on the project organization page to report unacceptable behavior.
Do not put private report data in public issues.
